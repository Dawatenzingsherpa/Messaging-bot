# Dawa Liquor Store - Facebook Messenger Bot

A simple Facebook Messenger chatbot built with Node.js and Express.

I created this project as a learning project to understand how Facebook Messenger bots work with a backend server.

## About the Project

This bot was created for the Dawa Liquor Store Facebook page.

The bot can receive messages from users and send different responses based on the user's input.

It also uses buttons to create a simple conversation flow.

Facebook Page:
https://www.facebook.com/profile.php?id=61556779809034

## Features

- Receive messages from Facebook Messenger
- Send automatic replies
- Interactive buttons
- Handle button selections
- Create different conversation flows
- Facebook webhook integration
- Node.js backend
- Deployable on Render
